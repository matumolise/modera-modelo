# Tesis Modelo IA

Implementación del DGM sintético y pipeline de Machine Learning para el MVP de tesis.

## Flujo

1. Configuración del DGM.
2. Generación de población sintética.
3. Generación de comportamiento.
4. Construcción de features.
5. Validación y sanity checks.
6. Generación del dataset final.
7. Entrenamiento y evaluación de modelos.

## Entorno

Python 3.10

Dependencias definidas en `requirements.txt`.
